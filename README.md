# Verilog
- All necessary SystemVerilog files are under verilog/bsc_map
- The files are, by default, calibrated for N=2000. Simply change DIMENSIONS in the testbench (tb_complete) to the desired dimensionality and use the appropriate item memory by renaming it to `item_mem_1.sv`
- For the architecture, use the appropriate bundler and rename it to `bundler_cont.sv`
